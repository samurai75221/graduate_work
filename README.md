## ✨ Возможности

- **🔍 Автоматический поиск** - бот анализирует ваш возраст, город и пол для подбора кандидатов
- **📸 Топ фотографий** - показывает 3 самые популярные фотографии профиля (по лайкам)
- **💾 Избранное** - возможность сохранять понравившихся пользователей
- **🚫 Черный список** - пользователи из черного списка не попадаются при поиске
- **💬 Простое управление** - все команды текстовые, никаких сложных интерфейсов
- **📁 Локальное хранение** - все данные сохраняются в JSON файлы на вашем диске

- Аккаунт ВКонтакте
