# VK Dating Bot 🤖

[![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)](https://python.org)
[![VK API](https://img.shields.io/badge/VK%20API-5.131-blue.svg)](https://vk.com/dev)

Бот для знакомств в социальной сети ВКонтакте. Автоматически подбирает пользователей по вашим критериям и позволяет сохранять понравившихся в избранное.

## ⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ О БЕЗОПАСНОСТИ

**НИКОГДА не выкладывайте в публичный доступ файлы с токенами доступа!**

- Токен доступа дает полный доступ к управлению вашей группой ВКонтакте
- Если токен попал в открытый доступ - НЕМЕДЛЕННО отзовите его в настройках группы
- В этом проексе токен хранится в файле `.env`, который добавлен в `.gitignore`
- Перед выгрузкой на GitHub убедитесь, что файл `.env` НЕ включен в коммит

## Возможности

- 🔍 Автоматический поиск пользователей на основе вашего профиля
- 📸 Показ топ-3 фотографий профиля (по лайкам) с отправкой как attachment
- 💾 Сохранение пользователей в избранное вместе с их фотографиями
- 📋 Просмотр списка избранных с детальной информацией
- 🚫 Черный список (исключает неподходящих кандидатов)
- 💬 Простое управление через текстовые команды
- 🔒 Безопасное хранение токена через переменные окружения
